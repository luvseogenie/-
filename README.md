# 쿠팡 소싱 프로그램

쿠팡 카테고리별 판매량순 상품을 훑어서 가격·리뷰·28일 판매량·전환율 조건에 맞는 상품을 걸러내는 프로그램입니다.
내 PC에서 실행되며, 브라우저에서 대시보드로 조작합니다.

## 설치 (처음 한 번)

1. 이 폴더를 통째로 PC에 내려받습니다 (GitHub에서 `Code › Download ZIP` 후 압축 해제).
2. `1_install.bat` 을 더블클릭합니다. 파란 글씨의 PowerShell 창이 열리고, 파이썬이 없으면 자동으로 받아 설치합니다 (5~10분).
3. "설치 완료!" 메시지가 뜨면 아무 키나 눌러 창을 닫습니다.
   실패하면 폴더에 생기는 `설치기록.txt` 와 화면 캡처를 개발자에게 보내주세요.

## 실행

- `2_run.bat` 을 더블클릭하면 창이 하나 뜨고, 잠시 후 브라우저에 대시보드가 열립니다.
- 그 창을 닫으면 프로그램이 종료됩니다.
- 대시보드 주소: http://127.0.0.1:8765/

## 업데이트

- 프로그램이 켜진 상태: 대시보드 `도구 › 프로그램 업데이트` 를 누르면 최신 코드를 받고 자동으로 다시 시작합니다.
- 프로그램이 꺼진 상태: `3_update.bat` 을 더블클릭합니다.

## 사용 순서

1. **무엇을 찾을지**: 1차 카테고리를 체크하면 쿠팡에서 2차·3차 카테고리를 불러옵니다 (크롬 창이 열립니다).
   키워드나 쿠팡 링크로 찾을 수도 있습니다.
2. **상품 조건**: 판매가격, 리뷰 수, 28일 판매량, 최소 전환율, 조사할 페이지 수를 정합니다.
3. **소싱 시작**: 최하위 카테고리마다 판매량순 120개씩 목록을 수집합니다.
4. **28일 판매량 분석**: 쿠팡 윙 로그인 세션으로 상품마다 28일 판매·조회수를 조회합니다.
   (처음에는 `도구 › 윙 캡처 모드`로 조회 방식을 잡아야 합니다. 아래 참고)
5. 결과 표에서 필터·정렬·검색을 하고, 보관함에 저장하거나 엑셀로 내려받습니다.

## 윙 캡처 모드 (처음 한 번)

1. `도구 › 윙 로그인 창 열기` 로 윙에 로그인합니다.
2. `도구 › 윙 캡처 모드 시작` 을 누릅니다.
3. 열린 브라우저에서 윙의 "최근 28일 판매량·조회수"가 보이는 화면으로 가서 상품을 하나 검색합니다.
4. `도구 › 윙 캡처 모드 종료` 를 누르고, `도구 › 윙 캡처 요약 보기` 의 내용을 복사해서 개발자에게 보냅니다.
5. 개발자가 `data/wing_config.json` 을 만들어 주면 판매량 분석이 동작합니다.

## 폴더

- `setup/` : 설치·실행 스크립트(PowerShell). 직접 열 필요 없습니다.

- `data/` : 결과 DB, 브라우저 로그인 정보, 로그, 엑셀 파일. (개인 정보이므로 공유하지 마세요)
- `data/debug/` : 수집이 안 될 때 자동 저장되는 화면 캡처. 문제가 생기면 이 파일을 보내주세요.
- `data/wing-capture/` : 윙 캡처 결과.

## 주의

쿠팡 약관은 자동 수집을 제한하고, 윙 계정에 제재가 있을 수 있습니다.
요청 간 대기 시간을 두어 부담을 줄이지만, 실제 판매 계정과 분리해서 쓰는 것을 권합니다.
