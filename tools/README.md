# tools

쿠팡 화면 구조를 확인할 때 쓰는 일회성 스크립트입니다.
빌드나 설치 없이 Chrome DevTools 콘솔에 붙여넣어 실행합니다.

## list-page-dump.js

카테고리·검색 **목록 페이지**의 상품 카드 구조를 뽑습니다.

1. 쿠팡 카테고리 페이지를 엽니다
2. `F12` → **Console** 탭
3. 콘솔에 `allow pasting` 을 입력하고 Enter (Chrome이 붙여넣기를 막는 경우)
4. 이 파일 내용을 전부 복사해 붙여넣고 Enter
5. 결과가 클립보드에 복사됩니다

출력 내용
- 기존 selector가 몇 개를 찾았는지
- 상품 링크(`/vp/products/`)로 역추적한 카드 요소
- "한 달간 N명 구매" 문구가 목록 페이지에도 있는지
- 상품 카드 하나의 전체 구조 (클래스명 + 텍스트 앞부분)

목록 페이지에는 개인정보가 없어 마스킹하지 않습니다.
상품 상세 페이지(리뷰 포함)는 `extension/dist/selector-dump.js` 를 쓰세요.
그쪽은 리뷰 본문·작성자명을 자동으로 가립니다.
