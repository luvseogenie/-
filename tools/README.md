# tools

쿠팡 화면 구조를 확인할 때 쓰는 일회성 스크립트입니다.
빌드나 설치 없이 Chrome DevTools 콘솔에 붙여넣어 실행합니다.

## parse-check.js  ← 먼저 이걸 쓰세요

카테고리 페이지에서 **상품이 몇 개 잡히고 어떤 값이 읽히는지** 바로 보여줍니다.
확장 프로그램과 같은 방식(selector → 링크 앵커 → 값의 형태)으로 동작합니다.

1. 쿠팡 카테고리 페이지를 엽니다 (상품이 화면에 보이는 상태)
2. `F12` → **Console** 탭
3. Chrome이 막으면 `allow pasting` 입력 후 Enter
4. 이 파일 내용을 전부 복사해 붙여넣고 Enter
5. 페이지 위에 뜬 박스에서 **[복사]** → 채팅창에 붙여넣기

출력 예시
```
감지된 상품 카드: 36개   (경로: a[href*='/vp/products/'] (링크 앵커))
정상 추출 가능:   36개   / 제외 0개

[필드별 추출 성공]
  상품명   36/36
  가격     36/36   (경로: 형태(13,900+원))
  리뷰수   읽음 34/36 (나머지는 리뷰 0건)
  평점     36/36   (경로: width%)
  배송     36/36
```

## list-page-dump.js

parse-check.js 결과가 나쁠 때, 무엇을 고쳐야 하는지 알아내는 용도입니다.

카테고리·검색 **목록 페이지**의 상품 카드 구조를 뽑습니다.

1. 쿠팡 카테고리 페이지를 엽니다
2. `F12` → **Console** 탭
3. 콘솔에 `allow pasting` 을 입력하고 Enter (Chrome이 붙여넣기를 막는 경우)
4. 이 파일 내용을 전부 복사해 붙여넣고 Enter
5. 결과가 클립보드에 복사됩니다

출력 내용
- 기존 selector가 몇 개를 찾았는지
- 상품 링크(`/vp/products/`)로 역추적한 카드 요소
- "한 달간 N명 구매" 문구가 목록 페이지에도 있는지
- 상품 카드 하나의 전체 구조 (클래스명 + 텍스트 앞부분)

목록 페이지에는 개인정보가 없어 마스킹하지 않습니다.
상품 상세 페이지(리뷰 포함)는 `extension/dist/selector-dump.js` 를 쓰세요.
그쪽은 리뷰 본문·작성자명을 자동으로 가립니다.
