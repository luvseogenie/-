순이익 = 광고 마진(Σ 판매량 × 그 날짜에 적용되는 옵션 마진) − 집행 광고비×1.1(부가세). 월 합계 열의 광고수익률·CPC·클릭률·전환율은 월 누계 기준으로 다시 계산한 값입니다. 붉은 배경은 마진이 등록되지 않은 옵션의 판매가 포함된 날입니다.

광고센터 → 광고 관리 → 매출 성장 → 어제 화면의 숫자를 그대로 적습니다. 퍼센트 항목(목표효율·전환율·클릭률)은 화면에 보이는 % 단위 숫자 그대로 적습니다 (예: 400, 7.8, 0.15).

파일로 가져오기 (반자동)

판매자센터 → 비즈니스 인사이트 → 판매분석 → 어제 → 엑셀 다운로드 → 상품별 판매 리포트 파일을 그대로 올리면 됩니다. 광고는 CSV/XLSX(캠페인 이름, 목표효율, 광고예산, 집행 광고비, 광고전환 매출, 전환율, 클릭률, 노출수, 클릭수, 광고전환 판매수) 로 올리거나 '일별 광고 입력' 탭에서 직접 입력합니다. 같은 날짜를 다시 올리면 덮어씁니다.
