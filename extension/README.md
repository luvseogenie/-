# 크롬 확장 프로그램: 쿠팡 광고계산기 수집기

이미 로그인해 둔 크롬에서 쿠팡 판매자센터·광고센터 화면의 **표를 그대로 읽어** 로컬 광고계산기 서버로 보냅니다.
로그인·이메일 인증·봇 차단 문제가 없고, 쿠팡 화면이 바뀌어도 표의 헤더 이름으로 열을 찾으므로 잘 버팁니다.

## 설치 (1회)
1. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
3. 로컬 서버 실행: `python -m coupang_calc serve`

## 매일 하는 일 (반자동, 클릭 2번)
1. 판매자센터 → 비즈니스 인사이트 → 판매분석 → **어제** (상품별 표가 보이는 상태)
2. 확장 프로그램 아이콘 → **이 페이지 → 판매 데이터 보내기**
3. 광고센터 → 광고 관리 → 매출 성장 → **어제**
4. 확장 프로그램 아이콘 → **이 페이지 → 광고 데이터 보내기**

날짜는 화면의 날짜 선택기에서 찾고, 못 찾으면 어제로 봅니다. 팝업의 날짜 칸에 직접 넣어도 됩니다.
표가 여러 페이지로 나뉘면 페이지를 넘기며 같은 버튼을 다시 누르면 됩니다(같은 날짜·옵션은 덮어쓰기).

## 완전 자동 (선택)
설정 페이지에서 판매분석 URL 과 광고 관리 URL(각각 '어제' 를 누른 상태의 주소)을 넣고 **매일 자동 수집** 을 켜면,
지정한 시각에 백그라운드 탭을 열어 표를 읽고 닫습니다. 크롬이 켜져 있어야 하며, 서버가 꺼져 있으면 큐에 보관했다가 다음에 보냅니다.

## 표를 못 찾을 때
팝업의 "이 페이지에서 찾은 표" 를 열면 페이지에서 인식한 표와 헤더가 나옵니다.
- 판매 표: 헤더에 `옵션` 과 `매출`(또는 `판매`) 이 있어야 합니다.
- 광고 표: 헤더에 `캠페인` 과 `광고비`/`노출`/`예산`/`클릭` 중 하나가 있어야 합니다.
서버가 인식하는 열 이름 별칭은 `coupang_calc/sales_report.py` 와 `coupang_calc/ads_report.py` 의 목록에 추가할 수 있습니다.
